РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ - Сборщик Заказов (Offline Assembler)

Это приложение предназначено для помощи в сборке заказов с использованием терминала сбора данных (ТСД) или обычного Android-смартфона.

=== 1. НАЧАЛО РАБОТЫ ===

При первом запуске необходимо настроить рабочие папки. Нажмите на значок "Настройки" (шестеренка) в правом верхнем углу:

1. "Выбрать папку с файлами (Вход)":
   - Укажите папку, куда вы будете загружать исходные Excel-файлы с заданиями на сборку.
   - Приложение будет автоматически показывать список файлов из этой папки на главном экране.

2. "Выбрать папку для сохранения (Выход)":
   - Укажите папку, куда будут сохраняться готовые отчеты о сборке.

=== 2. ПРОЦЕСС СБОРКИ ===

1. На главном экране выберите Excel-файл из списка.
2. Подтвердите начало сборки.

Экран сборки:
- В центре отображается текущий товар, который нужно найти (Артикул, Название, Штрихкод, План/Факт).
- Сканируйте штрихкод товара или вводите его вручную.
- Если товар верный, счетчик "Факт" увеличится.
- Когда количество собрано, приложение автоматически перейдет к следующей позиции.

Управление коробками:
- Внизу экрана указан номер текущей коробки (по умолчанию №1).
- Нажмите кнопки "-" или "+", чтобы изменить номер коробки. Все последующие товары будут привязаны к выбранной коробке.

=== 3. ПРОСМОТР И РЕДАКТИРОВАНИЕ ===

Нажмите кнопку "Список" (внизу слева), чтобы увидеть все позиции:
- Зеленые: собраны полностью.
- Желтые: собраны частично или с избытком.
- Красные: не собраны.

Редактирование:
- Нажмите на любой товар в списке.
- В появившемся меню можно:
  - Изменить собранное количество (ввести вручную).
  - Изменить номер коробки для этого товара.

=== 4. ЗАВЕРШЕНИЕ СБОРКИ ===

Когда все товары собраны, нажмите кнопку "Завершить" (внизу справа).

Если есть расхождения (несобранные товары):
- Приложение покажет предупреждение.
- Вы можете вернуться и дособрать, либо завершить досрочно.
- При досрочном завершении несобранные товары будут помечены как пропущенные.

=== 5. РЕЗУЛЬТАТ ===

После завершения создается Excel-файл в папке "Выход".
Имя файла: "Сборка_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.xlsx"

Формат отчета:
1. Блок "Расхождения": список товаров, где план не совпадает с фактом.
2. Блок "Информация о поставке": данные из исходного файла.
3. Блок "Коробки":
   - Товары сгруппированы по номерам коробок.
   - Для каждой коробки указаны: Количество, Артикул, Штрихкод.

На финальном экране можно:
- "Открыть файл": открыть отчет в Excel/Google Таблицах.
- "Поделиться": отправить файл через Telegram, WhatsApp, Почту и т.д.
- "В меню": вернуться к выбору нового задания.

=== ВОЗМОЖНОСТИ ===
- Темная тема (Dark Mode) с яркими акцентами.
- Автосохранение: если приложение закроется, при следующем запуске можно продолжить сборку.
- Поддержка сканеров штрихкодов (в режиме клавиатуры).
